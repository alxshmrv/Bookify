### Полное руководство по Agent Skills в Claude

**Agent Skills** — это мощный инструмент, который позволяет научить Claude выполнять специфические, многошаговые или кастомные задачи, следуя вашим инструкциям. Вместо того чтобы каждый раз писать длинный и сложный промпт, вы один раз создаете "навык", и Claude будет автоматически использовать его, когда ваш запрос будет соответствовать описанию этого навыка.

---

#### 1. Основная концепция: Как это работает?

Представьте, что у вас есть внутренняя библиотека для работы с API или собственный стиль для написания коммитов. Вместо того чтобы объяснять это Claude при каждом запросе, вы создаете навык.

Процесс выглядит так:
1.  **Загрузка описаний**: При запуске Claude сканирует папку с навыками и загружает только их названия и краткие описания. Это сделано для экономии контекста.
2.  **Сопоставление с запросом**: Когда вы отправляете запрос, Claude анализирует его и сравнивает с описаниями всех доступных навыков, чтобы найти наиболее подходящий.
3.  **Выполнение навыка**: Если найдено совпадение, Claude подгружает полные инструкции из файла навыка и следует им для выполнения вашего задания.

---

#### 2. Как создать свой навык

Навыки хранятся в виде файлов `SKILL.md` в специальной директории вашего проекта.

**Шаг 1: Создайте директорию**

В корне вашего проекта создайте папку `.claude`, а внутри нее — папку `skills`.
```
your-project/
├── .claude/
│   └── skills/
│       └── my_first_skill/
│           └── SKILL.md
└── ... (остальные файлы проекта)
```
Каждый навык должен находиться в своей собственной подпапке (например, `my_first_skill`).

**Шаг 2: Создайте файл `SKILL.md`**

Внутри папки вашего навыка создайте файл с названием `SKILL.md`. Этот файл состоит из двух частей:

*   **Frontmatter (Метаданные)**: В самом начале файла, между двумя `---`. Здесь указывается имя и описание навыка.
*   **Instructions (Инструкции)**: Основная часть файла, где вы подробно описываете, что и как должен делать Claude.

**Структура `SKILL.md`:**

```markdown
---
name: commit_message_formatter
description: A skill to format Git commit messages according to the company's conventional commit style. Use for requests about writing or rewriting commit messages.
---
# Git Commit Message Formatting Instructions

You are an expert at writing Git commit messages. Your task is to take a user's description of changes and format it into a conventional commit message.

The format is: `<type>(<scope>): <subject>`

1.  **Type**: Must be one of `feat` (new feature), `fix` (bug fix), `docs` (documentation), `style`, `refactor`, `test`, `chore`.
2.  **Scope** (optional): The part of the codebase affected.
3.  **Subject**: A short, imperative-tense description of the change.

Always ask for the 'type' if the user doesn't provide it.
```

#### 3. Лучшие практики и советы

##### **Как писать эффективное `description` (описание)**

Описание — самая важная часть, потому что именно по нему Claude решает, использовать навык или нет.

*   **Будьте точны и конкретны**. Не пишите просто "помощник по коду". Напишите "Форматирует SQL-запросы, используя стандарты `snake_case` для таблиц и `camelCase` для полей".
*   **Используйте ключевые слова**. Включите термины, которые пользователь может использовать в своем запросе. Например, "Git", "commit message", "conventional commit".
*   **Укажите, когда использовать навык**. Прямо напишите, для каких запросов предназначен этот навык. Пример: "Используй этот навык, когда пользователь просит написать или переписать сообщение коммита".
*   **Объясните, что навык делает**. Кратко, но ясно опишите конечный результат.

##### **Как писать качественные `Instructions` (инструкции)**

Здесь вы выступаете в роли тимлида, который ставит задачу Claude.

*   **Определите роль**. Начните с определения роли, например: "Ты — старший Python-разработчик, специализирующийся на Django".
*   **Дайте четкий пошаговый процесс**. Разбейте задачу на шаги. Используйте нумерованные списки или маркеры. Пример: "1. Проанализируй схему базы данных. 2. Определи нужные таблицы. 3. Напиши SQL-запрос, соединяя таблицы X и Y".
*   **Предоставьте примеры (few-shot prompting)**. Покажите примеры хорошего и, возможно, плохого результата. Это один из самых эффективных способов обучения.
*   **Задайте ограничения и правила**. Четко укажите, чего делать нельзя. Пример: "Никогда не используй `SELECT *`", "Всегда добавляй комментарии к сложным участкам кода".
*   **Требуйте задавать уточняющие вопросы**. Если для выполнения задачи не хватает информации, научите Claude спрашивать. Пример: "Если пользователь не указал версию API, обязательно спроси его об этом".
*   **Используйте XML-теги для структурирования**. Для сложных инструкций можно использовать теги, чтобы отделить примеры, правила или шаги, например `<example>`, `<rules>`, `<process>`.

---

#### Заключение

**Agent Skills** — это способ кастомизировать и специализировать Claude под ваши уникальные задачи и рабочий процесс. Правильно написанный навык значительно повышает точность и релевантнсть ответов, автоматизируя рутинные задачи и обеспечивая следование внутренним стандартам вашей команды.
